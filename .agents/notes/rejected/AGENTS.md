# AGENTS.md — Rejected Agent Notes

这些 Agent Note 是被考虑过并否决的提案，已冻结。遵循[根说明](../../../AGENTS.md) 与 [Agent Note 格式](../README.md#the-file-format)。

## 结论住在状态行

`Status: rejected — <一句话原因>` 是读者来这里要找的东西，所以那句话必须自己站得住：说出否决的判据，不只是「决定不做」。正文是那份被冻结的提案，保留它提案期的章节形状。

## 什么时候删掉而不是留着

只在它的理由还能阻止一个诱人的、有分量的错误时保留。一个合理的实现者不会再选的选项、一个已经被后续决策吸收的否决、一个只对已经不存在的代码有意义的否决——删掉文件，并修掉每一条入站链接。删掉之前确认没有独有的理由、备选方案或后果只存在于这一篇里。

## 永远不要改写正文

冻结就是冻结。后续讨论写进新的提案或新的已实现 note，并在这里留一条出站交叉链接指过去——反过来改这篇的正文，会让「我们否决过什么」这个记录失去可信度。

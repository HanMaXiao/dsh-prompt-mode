# AGENTS.md — Archived Agent Notes

这些 Agent Note 是封存的历史快照。遵循[根说明](../../../AGENTS.md) 与 [Agent Note 格式](../README.md#the-file-format)，但先读[归档与删除](../README.md#归档与删除)。

## 封存就是冻结

一篇归档 note 一旦写下就永久冻结。不要编辑、重排、更新、移动或删除它，也不要把它当作当前行为的权威——它记录的是那个时间点上决定了什么，不是现在什么是真的。要表达「现在不是这样了」，改活跃的那篇，或者写一篇新的。

归档期间唯一允许的内容变更是搬动文件和插入 `Archived: YYYY-MM-DD` 行，以及修掉或删掉入站链接。别的都不行。

## 活跃正文可以引用历史

链进一篇归档 note 是允许的，只要那是刻意引用历史——「我们试过 X，代价是 Y」。引用它的那一节仍然陈述现在时的结论；归档 note 提供的是那次权衡的记录，不是当前的口径。

## 这里没有当前权威

任何关于当前行为的争论都不在这棵子树里结算。活跃的 lifecycle 树才是工作清单；本目录只回答「当时为什么那么定」。
